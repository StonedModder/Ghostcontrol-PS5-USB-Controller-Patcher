Existing project attribution is reference/view/MODEL-ATTRIBUTION.md. Its stated
changes include splitting connected controls, baking transforms, materials and
lighting changes and interactive controls. The native tools/convert-dualsense-model.py
further quantizes/clusters geometry into ui/assets/ghostcontrol/dualsense3d.gc3d;
that conversion and the native viewer are project modifications, not original
model-author work.

The public Sketchfab API independently confirms the named author and CC BY 4.0.
The retrieved GLB mirror embeds that same author, model URL and CC-BY-4.0 in its
asset.extras. The mirror is retained on G with a SHA-256, not claimed as a
byte-authenticated input of the native converter. That converter describes an
81-part studio input; the retrieved mirror has 48 mesh entries. The exact
studio input/preferred edit file is not present in the frozen Git source.
This is an identified third-party attribution/source-variant question, not an
invented absence of a license grant. CC BY does not itself require delivering
the original Blender file. If an adaptation's preferred source is required as
part of a GPL-covered work, the exact edit input must be established separately.
